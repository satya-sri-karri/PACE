# PACE

A personal finance decision simulator built for PROMPT RUN: manage a starting ₹10,000 budget across 30 days and see the consequences of each decision.

## Product

- Daily spending allowance after commitments, savings, and an emergency buffer
- Income, expense, bill, subscription, and savings records
- Purchase and emergency-expense previews with interconnected financial consequences
- Dated cash-flow forecast and explainable planning health
- Local browser persistence

Implementation and setup instructions will be added with the application source.

Built independently with AI-assisted development during the hackathon window.
